## 기능 개선 리스트 (Feature Improvement List)

### 1. 소셜 & 공유 기능
| # | 기능 | 설명 |
|---|------|------|
| 1-1 | SNS 공유 기능 강화 | 카카오톡, 인스타그램 스토리, 트위터 등으로 결과를 직접 공유할 수 있는 딥링크/공유 카드 지원 |
| 1-2 | 공유용 OG 이미지 자동 생성 | 결과 화면을 이미지로 자동 생성하여 SNS 미리보기(Open Graph)에 최적화 |
| 1-3 | 링크 초대 시스템 | 고유 링크를 통해 친구를 초대하면 바로 내 MBTI를 맞출 수 있는 페이지로 이동 |
| 1-4 | 그룹/단체 기능 | 친구 그룹을 만들어 그룹 내에서 서로의 MBTI를 맞추고 통계를 확인 |

### 2. 게이미피케이션
| # | 기능 | 설명 |
|---|------|------|

### 3. 분석 & 통계
| # | 기능 | 설명 |
|---|------|------|
| 3-1 | MBTI 오답 분석 | 내 MBTI를 사람들이 가장 많이 혼동하는 유형이 무엇인지 분석 제공 |
| 3-2 | 성격 유형별 통계 대시보드 | 전체 사용자 기준 가장 많이 맞추기 어려운 MBTI, 가장 쉬운 MBTI 등 통계 |
| 3-3 | 친밀도 지표 | 나를 가장 잘 맞춘 친구, 내가 가장 잘 맞춘 친구 등 관계 기반 통계 |
| 3-4 | MBTI 유형별 첫인상 분석 | "사람들이 나를 처음 보면 어떤 MBTI로 인식하는지" 통계 |
